# Lab #08 - Field Data Collection with ArcGIS Field Maps

**Date:** November 2024  
**Course:** GIS 3043C  
**Tools:** ArcGIS Field Maps & ArcGIS Online  

## Overview
Conducted mobile field data collection using the ArcGIS Field Maps application to capture infrastructure asset locations (such as light poles, manhole covers, and utility features) paired with linked geotagged site photographs.

## Methods
* **Mobile Field Setup:** Configured the ArcGIS Field Maps application using institutional organizational credentials and accessed the designated operational web map layer.
* **Asset Data Collection:** Traversed the study area to capture precise spatial coordinates for ten individual infrastructure features via mobile GPS tracking.
* **Photo Attachment & Integration:** Captured high-resolution context photographs directly through the Field Maps application interface to establish direct linkage between digital media assets and spatial point features within the geodatabase.
* **Verification & Documentation:** Reviewed and validated attribute tables, spatial point distributions, and photo attachment relationships within ArcGIS Online Map Viewer to ensure complete data integrity.

## Skills Demonstrated
* Mobile GIS Data Collection & GPS Field Navigation via ArcGIS Field Maps
* Geotagged Media Attachment & Attribute Management
* Quality Control & Data Verification in ArcGIS Online
* Spatial Asset Mapping & Infrastructure Documentation
