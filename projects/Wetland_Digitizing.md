# Lab #03 - Wetland Digitizing

**Date:** October 2024  
**Course:** GIS 3043C  
**Tools:** ArcGIS Pro  

## Overview
Digitized missing wetland polygons within the Factory Project site using high-resolution color infrared aerial imagery. Prepared a professional map layout adhering to strict scale and symbolization requirements.

## Methods
* **Data Acquisition & Preparation:** Loaded the project workspace and referenced `Panel_5.jpg` to identify unmapped wetlands within the Factory Project area.
* **Feature Digitization:** Digitized eight new wetland polygons over the color infrared imagery base map, ensuring precise boundary alignment and topological accuracy.
* **Symbolization & Labeling:** Symbolized wetland polygons as hollow shapes with distinct yellow borders. Applied a custom label expression to display both the Wetland ID (`WETL_ID`) and the corresponding `FLUCFCS code`.
* **Layout Design & Export:** Configured the final map layout to a precise scale of 1:4,800. Integrated all standard cartographic elements (neatline, north arrow, scale bar, legend, and custom title) and exported the layout at 300 DPI to `Lab_03_Keefe.pdf`.

## Skills Demonstrated
* Feature Digitization & Spatial Editing in ArcGIS Pro
* Custom Label Expressions (Multi-attribute labeling)
* Color Infrared (CIR) Imagery Interpretation
* Cartographic Scale Management & Layout Design
